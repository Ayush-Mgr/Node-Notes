### Supervised Learning

**Definition:** Learns from **labeled data** (input + correct output).

**Goal:** Predict a known target.

**Examples:**

- House Price Prediction → Regression
    
- Email Spam Detection → Classification
    

**Models:**

- Linear Regression
    
- Logistic Regression
    
- Decision Tree
    
- Naive Bayes
    

**Example:**

```text
Study Hours → Exam Marks
```

Model learns relationship and predicts marks.

---

### Unsupervised Learning

**Definition:** Learns from **unlabeled data** (no correct output provided).

**Goal:** Discover hidden patterns or groups.

**Examples:**

- Customer Segmentation
    
- Market Basket Analysis
    

**Models:**

- K-Means Clustering
    
- Hierarchical Clustering
    

**Example:**

```text
Customer Data → Find similar customer groups
```

---

### Quick Comparison

|Supervised|Unsupervised|
|---|---|
|Labeled Data|Unlabeled Data|
|Known Output|No Output|
|Prediction|Pattern Discovery|
|Classification, Regression|Clustering|
|Linear Regression, Decision Tree, Logistic Regression, Naive Bayes|K-Means, Hierarchical Clustering|

### 2-Mark Answer

> **Supervised learning** uses labeled data to predict outputs (e.g., Linear Regression, Decision Tree), whereas **Unsupervised learning** uses unlabeled data to discover hidden patterns or clusters (e.g., K-Means, Hierarchical Clustering).

## Clustering vs classification
### Clustering (Unsupervised)

The model **doesn't know what a table is**.

It only sees features:

```text
Object A:
4 legs
flat top
wood
height 75cm

Object B:
4 legs
flat top
metal
height 70cm
```

The algorithm says:

> "These objects look similar, I'll put them in Group 1."

It might create:

```text
Group 1 → tables
Group 2 → chairs
Group 3 → lamps
```

But it never knows the word **"table"**. Humans look at Group 1 and say, "Ah, those are tables."

This is **K-Means Clustering**.

---

### Classification (Supervised)

Now imagine the training data already contains labels:

```text
4 legs, flat top, wood  → Table
4 legs, seat, wood      → Chair
```

The model learns:

> "Objects with these characteristics are usually labeled 'Table'."

When a new object arrives:

```text
4 legs, flat top, glass
```

The model predicts:

```text
Table
```

because it learned from labeled examples.

---

### Easy Memory Trick

**Classification = Teacher gives answers**

```text
Picture → Cat
Picture → Dog
Picture → Cat
```

Model learns labels.

---

**Clustering = No teacher**

```text
Picture
Picture
Picture
```

Model groups similar things together and says:

```text
Group A
Group B
Group C
```

Humans later decide what those groups mean.

So your example:

> "4 legs + flat top + furniture together because they are alike"

That's **clustering (unsupervised)**, not classification. Classification would require someone to have already told the model, "These examples are tables."
