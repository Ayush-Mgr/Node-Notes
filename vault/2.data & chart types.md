# 1. Data Types

Data types describe the kind of values stored in a dataset. They determine how data can be analyzed and visualized.

## A. Categorical (Qualitative) Data

Represents groups or categories rather than numerical values.

**Examples:**

- Gender (Male, Female)
    
- Blood Group (A, B, AB, O)
    
- Department (HR, Sales, IT)
    
- Country
    

### Types

- **Nominal:** Categories with no natural order (e.g., Color: Red, Blue, Green).
    
- **Ordinal:** Categories with a meaningful order (e.g., Small, Medium, Large).
    

---

## B. Numerical (Quantitative) Data

Represents measurable values that can be counted or calculated.

**Examples:**

- Age
    
- Height
    
- Salary
    
- Temperature
    

### Types

- **Discrete:** Countable values (e.g., Number of Students, Number of Cars).
    
- **Continuous:** Measurable values (e.g., Weight, Height, Time).
    

---

# 2. Categorical vs Numerical Data

|Feature|Categorical Data|Numerical Data|
|---|---|---|
|Nature|Labels or categories|Numbers|
|Arithmetic Operations|Not possible|Possible|
|Examples|Gender, City, Color|Age, Income, Weight|
|Types|Nominal, Ordinal|Discrete, Continuous|
|Best Charts|Bar Chart, Pie Chart|Histogram, Line Chart, Scatter Plot|

---

# 3. Time Series Charts

A **Time Series Chart** displays data collected over time to show trends, seasonal patterns, and changes.

### Characteristics

- X-axis represents **time** (days, months, years).
    
- Y-axis represents the measured variable.
    
- Data points are connected in chronological order.
    

### Common Time Series Charts

### 1. Line Chart

Most common chart for showing trends over time.

**Example:**

- Monthly sales
    
- Daily stock prices
    
- Annual rainfall
    

### 2. Area Chart

Shows trends while emphasizing cumulative totals.

### 3. Candlestick Chart

Used in financial markets to display stock price movements.

### Applications

- Weather forecasting
    
- Stock market analysis
    
- Sales forecasting
    
- Website traffic analysis
    
- Temperature monitoring
    

---

# 4. Geospatial Visualization

**Geospatial Visualization** displays data based on geographic locations using maps.

It helps analyze **where** events occur and identify regional patterns.

### Examples

- COVID-19 cases by state
    
- Population density
    
- Crime rates by city
    
- Election results
    
- Sales by region
    

### Types of Geospatial Visualizations

### 1. Choropleth Map

Uses different colors or shades to represent values across regions.

### 2. Symbol Map

Uses symbols or circles of different sizes to represent data.

### 3. Heat Map

Shows areas with higher data concentration using color intensity.

### 4. Dot Distribution Map

Represents individual occurrences using dots.

### Applications

- GPS navigation
    
- Urban planning
    
- Disaster management
    
- Business expansion
    
- Environmental monitoring

# 5. Chart Selection

Choosing the correct chart ensures data is presented clearly and accurately.

| Purpose                             | Best Chart               |
| ----------------------------------- | ------------------------ |
| Compare categories                  | Bar Chart                |
| Show trends over time               | Line Chart               |
| Show proportions                    | Pie Chart                |
| Show frequency distribution         | Histogram                |
| Show relationship between variables | Scatter Plot             |
| Detect outliers                     | Box Plot                 |
| Compare multiple variables          | Grouped Bar Chart        |
| Show geographic data                | Choropleth Map, Heat Map |
| Show hierarchy                      | Tree Map                 |
| Show cumulative values              | Area Chart               |

---

## Chart Selection Guide

```text
What do you want to show?
        │
        ├── Compare Categories → Bar Chart
        │
        ├── Trend Over Time → Line Chart
        │
        ├── Parts of Whole → Pie Chart
        │
        ├── Distribution → Histogram / Box Plot
        │
        ├── Relationship → Scatter Plot
        │
        ├── Geographic Data → Maps
        │
        └── Hierarchical Data → Tree Map
```

# Exam Answer (5 Marks)

### Data Types

Data is classified into **Categorical (Qualitative)** and **Numerical (Quantitative)**. Categorical data represents labels or groups, while numerical data represents measurable values.

### Categorical vs Numerical

Categorical data includes values like gender or department and is visualized using bar or pie charts. Numerical data includes age, income, and weight and is visualized using histograms, line charts, or scatter plots.

### Time Series Charts

Time series charts display data over time to identify trends and patterns. Common examples are **Line Charts**, **Area Charts**, and **Candlestick Charts**.

### Geospatial Visualization

Geospatial visualization represents data on maps to analyze geographic patterns. Common types include **Choropleth Maps**, **Heat Maps**, **Symbol Maps**, and **Dot Distribution Maps**.

### Chart Selection

Select charts based on the purpose:

- **Bar Chart** – Compare categories
    
- **Line Chart** – Trends over time
    
- **Pie Chart** – Proportions
    
- **Histogram** – Distribution
    
- **Scatter Plot** – Relationships
    
- **Maps** – Geographic data
    

### Memory Tip

**"Compare–Trend–Part–Distribution–Relation–Location"**

- Compare → **Bar Chart**
    
- Trend → **Line Chart**
    
- Part of Whole → **Pie Chart**
    
- Distribution → **Histogram**
    
- Relationship → **Scatter Plot**
    
- Location → **Map**
