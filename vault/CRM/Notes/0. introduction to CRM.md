Customer relation management refers to the tools, technologies, and strategies businesses use to manage interactions with current and potential customers

**Evolution**

| Era       | Description                                                |
| --------- | ---------------------------------------------------------- |
| 1960s–70s | Manual customer records and personal selling               |
| 1980s     | Database Marketing (customer information stored digitally) |
| 1990s     | CRM software (Salesforce Automation)                       |
| 2000s     | Web-based CRM and cloud computing                          |
| 2010s     | Social CRM and Mobile CRM                                  |
| Present   | AI, Machine Learning, Big Data, Predictive CRM             |
