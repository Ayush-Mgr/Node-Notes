it is the process of gathering information from the cleaned preprocessed data
core :
- **What is the Shape? (Distribution):** You need to know if your numerical columns look like a nice, symmetrical bell curve (Gaussian), or if they are wildly skewed to the left or right. This tells you whether you should use the **Mean** or the **Median** to fill in blank spaces later.
-  **Finding Outliers**
- Multicollinearity: feafures that are too same
- Missingness: cause of missing data 

types:
1. **Univariate Analysis (One Column at a Time)**
	- **Univariate analysis** studies a single feature
2. **Multivariate Analysis (Group of columns data at a Time)**
	- **multivariate analysis** studies *relationships* among multiple features

| Question                                  | Analysis Type                 | Common Methods                                    |
| ----------------------------------------- | ----------------------------- | ------------------------------------------------- |
| **What is the Shape? (Distribution)**     | **Univariate**                | Histogram, Density Plot, Skewness                 |
| **Where are the Liars? (Outliers)**       | **Univariate** (mostly)       | Box Plot, IQR, Z-Score                            |
| **Who is Gossiping? (Multicollinearity)** | **Multivariate**              | Correlation Matrix, Heatmap, VIF                  |
| **What is the Void? (Missingness)**       | **Univariate + Multivariate** | Missing Value Count, Missingness Pattern Analysis |
