If you're asking about **Graph Analysis** in Big Data Analytics:

### What is a Graph?

A graph is a data structure consisting of:

```text
Nodes (Vertices)
+
Edges (Connections)
```

Example:

```text
Ayush ---- Rahul
  |
  |
 Priya
```

* Nodes = Ayush, Rahul, Priya
* Edges = Friendships

---

### Why use Graphs?

Graphs help analyze **relationships** between entities.

Examples:

* Social Networks (Facebook, LinkedIn)
* Road Networks (Google Maps)
* Recommendation Systems (Amazon, Netflix)
* Communication Networks

---

### Key Components

#### Node (Vertex)

Represents an object.

Example:

```text
Person
City
Website
```

#### Edge

Represents a relationship.

Example:

```text
Friend of
Connected to
Purchased with
```

---

### Graph Analysis Tasks

#### 1. Community Detection

Find groups of closely connected nodes.

Example:

```text
Friend Group A
Friend Group B
```

---

#### 2. Shortest Path

Find the shortest route between two nodes.

Example:

```text
Google Maps
```

---

#### 3. Centrality

Find the most important node.

Example:

```text
Most influential person in a social network
```

---

### Social Network Analysis

A special application of graph analysis.

Example:

```text
Users = Nodes
Friendships = Edges
```

Used to find:

* Influencers
* Communities
* Information spread

---

### Exam Answer

> Graph analysis is the study of relationships between entities represented as nodes and edges. It is used in social networks, recommendation systems, communication networks, and route optimization to discover patterns, communities, and important connections. 

### One-Line Memory Trick

```text
Graph = Objects + Relationships
Node = Object
Edge = Relationship
```

Think:

> **Table data stores attributes; Graph data stores relationships.** That's the big idea.
