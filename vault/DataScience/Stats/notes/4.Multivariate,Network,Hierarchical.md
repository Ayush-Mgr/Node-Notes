# 1. Multivariate Visualization

**Multivariate Visualization** is the graphical representation of data involving **three or more variables** simultaneously. It helps analyze complex relationships among multiple variables in a single visualization.

## Purpose

- Discover relationships between variables.
    
- Identify patterns and trends.
    
- Detect outliers.
    
- Compare multiple dimensions of data.
    

### Common Multivariate Charts

#### A. Scatter Plot

Shows the relationship between two numerical variables.

**Example:** Height vs Weight

#### B. Bubble Chart

An extension of the scatter plot where:

- X-axis → Variable 1
    
- Y-axis → Variable 2
    
- Bubble Size → Variable 3
    
- Bubble Color → Variable 4 (optional)
    

**Example:** Country GDP, Population, and Life Expectancy.

#### C. Parallel Coordinates Plot

Each variable has its own vertical axis, and observations are represented by lines crossing all axes.

**Used for:**

- High-dimensional datasets
    
- Machine learning
    
- Data mining
    

#### D. Heat Map

Represents values using color intensity.

**Used for:**

- Correlation matrices
    
- Website analytics
    
- Temperature distribution
    

### Applications

- Healthcare analytics
    
- Financial analysis
    
- Scientific research
    
- Machine learning
    
- Marketing analytics

# 2. Network Graphs

A **Network Graph** visualizes relationships (connections) between different entities.

### Components

### Node (Vertex)

Represents an object or entity.

Examples:

- Person
    
- Computer
    
- City
    
- Website
    

### Edge (Link)

Represents the relationship between two nodes.

Examples:

- Friendship
    
- Road
    
- Internet connection
    
- Communication
    

### Types of Network Graphs

#### Undirected Graph

Connections have no direction.

Example:  
Friendship Network

#### Directed Graph

Connections have a direction.

Example:  
Twitter followers

#### Weighted Graph

Edges have weights representing strength or distance.

Example:  
Flight distance between cities

### Applications

- Social media analysis
    
- Internet topology
    
- Recommendation systems
    
- Transportation networks
    
- Biological networks

# 3. Hierarchical Charts

**Hierarchical Charts** display data organized into parent-child relationships.

### Types of Hierarchical Charts

### A. Tree Diagram

Shows a hierarchy using connected branches.

Example:

```
Company
│
├── HR
├── Sales
└── IT
```

### B. Tree Map

Represents hierarchical data using nested rectangles.

- Rectangle size → Value
    
- Rectangle color → Category
    

### C. Sunburst Chart

Displays hierarchy using concentric circles.

Center → Parent

Outer Rings → Child categories

### D. Dendrogram

Tree-like structure commonly used in clustering analysis.

### Applications

- Organization charts
    
- File systems
    
- Product categories
    
- Family trees
    
- Machine learning (hierarchical clustering)

# 4. 3D Visualization

**3D Visualization** displays data using three dimensions (X, Y, and Z).

### Examples

- 3D Scatter Plot
    
- Surface Plot
    
- Terrain Map
    
- 3D Bar Chart
    

### Advantages

- Displays complex relationships
    
- Better representation of spatial data
    
- Useful in engineering and medical imaging
    

### Disadvantages

- Difficult to interpret
    
- Can distort perception
    
- Harder to compare values accurately
    
- Not recommended for simple datasets
    

### Applications

- Medical imaging
    
- Architecture
    
- Engineering
    
- Geographic Information Systems (GIS)
    
- Scientific simulations

# 5. Interactive Visualization

**Interactive Visualization** allows users to interact with charts instead of viewing static images.

### Features

### Zoom

Magnify specific parts of the data.

### Filter

Display only selected information.

### Drill Down

Navigate from summary data to detailed information.

### Tooltip

Shows additional information when hovering over data points.

### Animation

Displays changes over time dynamically.

### Cross Filtering

Selecting data in one chart updates related charts automatically.

### Advantages

- Better user engagement
    
- Easier exploration of data
    
- Faster analysis
    
- Personalized insights
    

### Common Tools

- Tableau
    
- Power BI
    
- Plotly
    
- D3.js
    
- Google Looker Studio

# Exam Answer (5 Marks)

### Multivariate Visualization

Multivariate visualization represents **three or more variables** in a single chart to analyze complex relationships. Common examples include **Bubble Charts, Heat Maps, Scatter Plots, and Parallel Coordinates**.

### Network Graphs

Network graphs display relationships between entities using **nodes** (objects) and **edges** (connections). They are widely used in social networks, communication systems, and transportation.

### Hierarchical Charts

Hierarchical charts represent **parent-child relationships**. Common types include **Tree Diagrams, Tree Maps, Sunburst Charts, and Dendrograms**.

### 3D Visualization

3D visualization represents data using **X, Y, and Z axes**. It is useful for engineering, GIS, and medical imaging but may be harder to interpret than 2D charts.

### Interactive Visualization

Interactive visualization enables users to explore data using **filters, zoom, drill-down, tooltips, and animations**, improving data analysis and decision-making.
