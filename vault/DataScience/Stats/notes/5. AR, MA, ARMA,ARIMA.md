## AR
[yt](https://www.youtube.com/watch?v=5-2C4eO4cPQ)
An AR model assumes that the current value is a linear combination of its own past values
>it allows us to predict the todays value $X_t$ uisng its past values the lags $X_t-k$


$$
X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \varepsilon_t
$$

where:

* $X_t$ = value at time $t$
* $c$ = constant (intercept)
* $\phi_i$ = coefficient of lag $i$
* $\varepsilon_t$ = white-noise error term
* $p$ = order of the AR model


### Sparse AR Model
AR model is often overfitted by its lags low value lags, for that we use the [[DataScience/Stats/notes/4. ACF & PCF|PACF chart]] to select the lags with significance PACF value above the threshold and the pacf chart complely isolates the lag from the low value lags reducing the overfitting and imprving the model 

**Textbook AR($p$) Model** — the rigid "solid block."

If $p=3$, you must use all lags:

$$
X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \phi_3 X_{t-3} + \varepsilon_t
$$

Uses:

$$
\{1,2,3\}
$$


**Sparse AR Model** — the flexible "à la carte menu."

Select only PACF-significant lags (e.g., 1, 2, 4, and 12):

$$
X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2}
      + \phi_4 X_{t-4}
      + \phi_{12} X_{t-12}
      + \varepsilon_t
$$

Uses:

$$
\{1,2,4,12\}
$$

and ignores all other lags.

**Key Idea:**

$$
\text{AR}(p): \{1,2,\ldots,p\}
$$

$$
\text{Sparse AR}: \{\text{only important lags}\}
$$

Sparse AR reduces noise, computation, and overfitting while retaining the most predictive lag relationships.

# Moving Average 
MA models predict using **past errors**: eg, the amount of eggs to buy for this month by calculating the amount of eggs got rotten or got short off this month.

[yt](https://www.youtube.com/watch?v=voryLhxiPzE)
It predicts the current point $\hat{f}_t$ using the long-run average $\mu$ and corrects for a fraction $\phi$ of the previous prediction error $\varepsilon_{t-1}$:

$$
\hat{f}_t = \mu + \theta \varepsilon_{t-q}
$$



where:

* $\hat{f}_t$ = predicted value at time $t$
* $\mu$ = average (baseline) value
* $\varepsilon_{t-1}$ = previous forecast error
* $\phi$ = error-correction coefficient


### How MA Works

Suppose your previous prediction was too low:

$$
\varepsilon_{t-1} > 0
$$

The model learns from that mistake and increases the next prediction.

If the previous prediction was too high:

$$
\varepsilon_{t-1} < 0
$$

The model lowers the next prediction.

The coefficient $\theta$ controls how strongly the model reacts to past mistakes.

## ARMA 

it is the combination of AR and MA  model, where data is stationary (I : intrigaated) 

where  
$$
X_t = c +
\underbrace{(\phi_1 X_{t-1} + \cdots + \phi_p X_{t-p})}_{\text{AR Part (Past Data)}} +
\underbrace{(\theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q})}_{\text{MA Part (Past Errors)}} +
\varepsilon_t
$$
