A database is a collection of data which is organize and stored in a computer system.
This database is managed using a database management system (DBMS)

```sql
CREATE DATABASE IF NOT EXISTS my_database_name;
```

DBMS is  an organized system of software, hardware, methods, and data.
SQL is a language that helps us communicate with this DBMS
