types of TABELS:

- Index tables: An index is technically not a separate type of table. It's a data structure created on a table to speed up data retrieval.
```SQL
CREATE INDEX idx_name
ON students(name);
```
- External tables : Data  outside of the database like csv , excel etc.
- Temporary Tables: Tables that exist temporarily, usually for the duration of a database session or transaction.Once the session ends, the temporary table is automatically removed (depending on the database).

```sql
CREATE TEMPORARY TABLE temp_students (
    id INT,
    name VARCHAR(50)
);
```



Creating table:
``` SQL
create table <table_name> (
  <column1_name> <data_type>,
  <column2_name> <data_type>,
  <column3_name> <data_type>,
  ...
)```
